# Medical Instrumentation

This repository contains academic projects related to medical instrumentation, biomedical sensors and physiological signal measurement.

The projects are from my bachelor's degree in electronics engineering at OsloMet and my ongoing master's studies in microelectronics and sensor technology at the University of Oslo.

The main focus is on practical measurement systems where electronics, sensors and software are combined to acquire and process physiological signals.

## Projects

### PPG and EMG instrumentation

A second-year electronics project focused on building two medical instrumentation systems:

- an EMG circuit for measuring muscle activity
- a PPG circuit for pulse measurement

The EMG signal was processed and used with Arduino to control a Braccio robot arm. The PPG circuit was used to measure changes in blood flow and pulse.

Main topics:
- EMG and PPG signal acquisition
- Analog filtering and amplification
- Arduino programming
- Physiological signal processing
- Testing with oscilloscope and lab equipment

### Deep muscle activity measurement using NIRS

Bachelor thesis project in electronics engineering.

The goal was to develop a prototype device for measuring changes in blood supply around the sural nerve using near-infrared spectroscopy (NIRS).

The project included research, circuit design, prototyping and testing of an optical biomedical measurement system.

Main topics:
- Near-infrared spectroscopy
- LED driver circuits
- Photodiode measurements
- Transimpedance amplifier
- Analog and digital signal processing
- PCB/circuit design
- Prototype development and testing

My main technical contribution was related to circuit design and coding.

### Stress estimation using sensor fusion

Ongoing master's thesis project.

The project investigates stress estimation using a combination of contactless radar measurements and wearable physiological sensors.

Sensors and signals:
- UWB radar
- EDA
- ECG / HRV

The goal is to investigate whether combining radar-based respiration/motion features with EDA and HRV can improve stress estimation compared to using single sensor modalities.

Main topics:
- Sensor fusion
- Signal processing
- Machine learning
- Radar-based physiological monitoring
- Electrodermal activity
- Heart rate variability
